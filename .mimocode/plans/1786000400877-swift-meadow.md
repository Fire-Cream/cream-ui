# cream-ui 实现计划

## 概述

基于 Element Plus 架构模式，构建一个简化版的 Vue 3 组件库。

## 技术栈

- **包管理**: pnpm workspaces
- **构建工具**: Vite + Rollup
- **语言**: TypeScript
- **样式**: SCSS + BEM
- **测试**: Vitest
- **文档**: VitePress

## 项目结构

```
cream-ui/
├── packages/
│   ├── cream-ui/          # 主包（发布入口）
│   ├── components/        # 所有 UI 组件
│   ├── hooks/             # 组合式函数
│   ├── utils/             # 工具函数
│   ├── theme-chalk/       # 主题样式
│   └── constants/         # 共享常量
├── play/                  # 开发调试 playground
├── docs/                  # 文档站
├── internal/
│   └── build/             # 构建配置
├── pnpm-workspace.yaml
└── package.json
```

### 阶段 2: 核心包实现

**目标**: 实现组件库的基础设施

#### 2.1 `packages/utils` - 工具函数

**文件**:
- `packages/utils/src/install.ts` - withInstall 工厂函数
- `packages/utils/src/vue.ts` - Vue 相关工具
- `packages/utils/src/types.ts` - 类型定义
- `packages/utils/package.json`

**核心实现**:
```typescript
// withInstall - 组件注册
export const withInstall = <T>(comp: T, name: string) => {
  const c = comp as any
  c.install = (app: App) => {
    app.component(name, c)
  }
  return comp
}
```

#### 2.2 `packages/hooks` - 组合式函数

**文件**:
- `packages/hooks/use-namespace.ts` - BEM 类名生成
- `packages/hooks/use-size.ts` - 组件尺寸
- `packages/hooks/index.ts` - 导出入口

**核心实现**:
```typescript
// useNamespace - BEM 命名空间
export const useNamespace = (block: string) => {
  const b = () => `ag-${block}`
  const m = (modifier: string) => `ag-${block}--${modifier}`
  const e = (element: string) => `ag-${block}__${element}`
  return { b, m, e }
}
```

#### 2.3 `packages/constants` - 共享常量

**文件**:
- `packages/constants/size.ts` - 尺寸常量
- `packages/constants/index.ts` - 导出入口
