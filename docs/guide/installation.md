# 安装

## 使用包管理器

推荐使用 pnpm 安装：

```bash
pnpm add cream-ui
```

或者使用 npm：

```bash
npm install cream-ui
```

或者使用 yarn：

```bash
yarn add cream-ui
```

## 浏览器引入

通过 CDN 引入：

```html
<!-- 引入样式 -->
<link rel="stylesheet" href="https://unpkg.com/cream-ui/dist/index.css" />

<!-- 引入 JavaScript -->
<script src="https://unpkg.com/cream-ui"></script>
```
